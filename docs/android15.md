# targetSdk 35 (Android 15) — версия 0.9.7

Техдолг, этап C (05.11.2026). Цель — перейти на compileSdk/targetSdk 35 так, чтобы вид и поведение не изменились.

## Что изменено

- `compileSdk`/`targetSdk` 34 → 35; `work-runtime-ktx` 2.9.1 → 2.10.5 (2.10 требует compileSdk 35).
  WorkManager 2.10 подтягивает `androidx.core` 1.12, где `PathParser.createPathFromPathData` помечен внутренним
  (lint RestrictedApi). Вызов собран в одну функцию `svgPath` (`ModernIcons.kt`) с пояснённым подавлением —
  публичной замены до API 33 нет, поведение то же.
- `SystemBarInsets.kt` + класс приложения `SmartHomeApp` (манифест `android:name`). Только на Android 15+:
  - у каждого экрана `android.R.id.content` получает отступы системных полос, выреза и клавиатуры (снизу — что
    больше) — как раньше делало само окно; Android 15 рисует окна под полосами принудительно;
  - под полосами рисуются их прежние цвета из темы (`statusBarColor`/`navigationBarColor`) слоем поверх фона окна
    (через `window.setBackgroundDrawable`: decorView сам переставляет свой фон). Прозрачный цвет темы (так платформа
    задаёт навигацию для приложений Android 15) рисуется чёрным — так система показывала его до 15;
  - `legacyWindowSize`: размер окна без полосы навигации и выреза — как `displayMetrics` до Android 15 (теперь
    `displayMetrics` включает полосы). Используют раскладка панели (`MainActivity`, `DashboardPanelController`),
    размещение новой плитки и ограничение размера (`TileSettingsActivity`), предпросмотр редактора климата.
  - До Android 15 код ничего не делает.
- Строка состояния на панели по-прежнему скрыта `FLAG_FULLSCREEN` (на Android 16 проверено эмулятором).
- Тест `SystemBarInsetsTest` (Robolectric SDK 35 и 28).

## Проверка вида

Эмулятор планшета 1920×1200, 240 dpi, Android 16 (API 36, google_apis), отдельный AVD `SHD_Tablet_API_36`;
поддельный HA на компьютере (тестовые данные, без реального дома). Плитки: «Сеть · Вход», «Инвертор · Выход»,
«Инвертор», «АКБ», «Климат» (без привязки датчиков). «До» — 0.9.6 debug (targetSdk 34), «после» — 0.9.7 debug,
установлено поверх (`install -r`, данные сохранены). Попиксельное сравнение снимков: главная, боковая панель,
настройки, редакторы «Электропитание», «Инвертор», «АКБ», «Климат», TileSettings (существующая плитка),
раскрытые «АКБ» и «Климат», диалог «Добавить» — отличаются только цифры часов. Клавиатура в настройках: содержимое
ужимается над ней.

Найдено и исправлено по ходу проверки (до исправления): белая полоса под навигацией на панели и экранах темы
Classic; предпросмотр редактора климата на ~10 px крупнее.

## Другие изменения Android 15 (по коду)

- Сервисы переднего плана: в приложении нет (WorkManager — без `setForeground`); ограничения `dataSync`/
  `BOOT_COMPLETED` не касаются.
- Safer intents: все явные намерения — к своим неэкспортируемым приёмникам/экранам без фильтров; без изменений.
- Запуск экранов из фона: `PendingIntent` установщика — широковещательный; окно подтверждения открывается из
  приёмника после нажатия «Установить», ночью сессия отменяется; открытие панели после замены пакета
  (`MY_PACKAGE_REPLACED`) — как и раньше, может блокироваться системой (не проверено на устройстве).
- PackageInstaller (`MODE_FULL_INSTALL`, `USER_ACTION_NOT_REQUIRED`) и SAF (`OPEN_DOCUMENT_TREE`,
  постоянное разрешение) — изменений поведения для targetSdk 35 нет.
- `elegantTextHeight` по умолчанию влияет на арабский/тайский и т. п.; кириллица и латиница — снимки совпали.

## Не проверено

- Реальный планшет (Samsung, Android 16), режим киоска (`startLockTask`), трёхкнопочная навигация, вырез камеры.
- Самообновление 0.9.6 → 0.9.7 через PackageInstaller (проверено только `adb install -r` на эмуляторе).
- Экраны первого запуска и PIN — только код и тест, снимков нет.
