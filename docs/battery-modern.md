# АКБ Modern

Новый тип плитки `battery_modern` («АКБ Modern (подробная)» в списке типов).
Прежняя плитка батареи (`battery`, Classic) не изменена: её дерево, рендерер
и формат конфигурации остались прежними.

## Компоненты

| Файл | Назначение |
| --- | --- |
| `BatteryModernConfig` | Шаблон строк, роли компактных зон, порядок/скрытие/свои строки, соглашение о знаке, порог ожидания. JSON в `tile.config.modern_battery`; остальные ключи config не трогаются. |
| `BatteryModernData` | `HaSession` (соединение + снимок текущей сессии), `BatteryReadings` (оценка достоверности), `PowerFlow`, форматирование. |
| `BatteryModernCard` | Компактный и развёрнутый вид; в редакторе зоны и строки кликабельны. Без сети, таймеров и постоянных анимаций. |
| `BatteryModernExpansion` | Раскрытие поверх панели, blur/затемнение, таймер 30 с, пауза, освобождение. |
| `BatteryModernDraft`, `BatteryModernEditorActivity` | Черновик и экран редактора; запись только «Сохранить». |

## Шаблон

«Сенсоры»: Батарея (SOC), Зарядка, Мощность, Мощность Inverted, Накопленная
энергия, Напряжение, Температура, Ток, Battery health, Cycles, Runtime.
«Диагностика»: Проблема, Уровень сигнала, Balancer, Charge MOSFET, Delta cell
voltage, Design capacity, Discharge MOSFET, Highest/Lowest cell voltage.

Все источники в шаблоне пусты: название строки — только подпись и роль, сущность
выбирает владелец. Компактные зоны (SOC, мощность, время, напряжение, температура)
берут строку по роли, поэтому редактирование зоны и строки списка — одна настройка.
Строки без источника показывают «—» или скрываются (переключатель плитки).

## Раскрытие

- Тап по плитке (без движения дальше 10 px) открывает отдельную карточку поверх
  панели: transform-анимация 300 мс от исходных координат; компактная плитка скрыта
  и после закрытия (250 мс) снова видна с прежними размерами/координатами. Конфигурация
  при раскрытии не пишется.
- Фон: API 31+ и не low-RAM — `RenderEffect.createBlurEffect` на дереве панели плюс
  лёгкое затемнение; иначе только затемнение (без снимков экрана и без работы в UI-потоке).
- Жесты распознаёт существующий `SensorWindowTouchHandler`: движение больше
  `scaledTouchSlop` — прокрутка (передаётся списку и не закрывает, даже с возвратом
  к началу), удержание дольше long-press — не тап, остальное — закрывающий тап по
  содержимому или свободному месту.
- Таймер 30 с перезапускают касания и прокрутка внутри карточки. Отрисовка событий HA
  таймер не трогает. Потеря фокуса окна (системный диалог, шторка) — пауза, возврат —
  новый отсчёт. Редактирование выполняется на отдельном экране: раскрытие панели при
  уходе с неё освобождается (`onResume` → перестроение панели), таймер не работает.
- Перестроение панели, удаление плитки (проверка при следующем касании), `onDestroy`
  отменяют анимации, таймер, blur и удаляют overlay.

## Достоверность данных

`MainUiState.haSession`: `connected` ставится по `auth_ok` текущего поколения,
`synced` — после применения первоначального снимка этой сессии; разрыв, новая
конфигурация и `disconnectWebSocket` сбрасывают оба флага. Хранилище состояний
не очищается.

| Состояние | Показ |
| --- | --- |
| Значение (в т. ч. `0`) | число с единицей HA или своей |
| `unknown` / `unavailable` | «Неизвестно» / «Недоступно» в списке, «—» в крупных зонах |
| Сущности нет в данных HA | «Нет сущности» |
| Значение не подтверждено новой сессией (stale) | «—» |
| Нет связи | «—», статус «Нет связи с Home Assistant» |
| Связь есть, снимка нет | «—», статус «Синхронизация с Home Assistant…» |

Шкала SOC без достоверного значения 0–100 нейтральна; постоянных анимаций нет,
рендерер не запускает сеть.

## Направление мощности

По умолчанию (BMS владельца): минус — «↓ Разряд», плюс — «↑ Заряд», модуль не больше
порога (20 по умолчанию, в единицах датчика) — «■ Ожидание», нет данных — «— Нет данных».
Подпись и стрелка различимы без цвета; знак и единица числа сохраняются. Переключатель
«Инвертировать знак мощности» — в настройке конкретной плитки.

## Проверка на физическом планшете (только с разрешения владельца)

Ничего не переключать, команд дому не отправлять; тестовую плитку после проверки
можно удалить. Данные приложения не очищать.

1. Установить debug-сборку поверх текущей (без удаления).
2. Режим редактирования → «+» → тип «АКБ Modern (подробная)» → название → «Сохранить».
   Убедиться, что Classic-плитки выглядят как прежде.
3. Нажать новую плитку в режиме редактирования → редактор. Проверить подсказку
   первого использования и её закрытие крестиком.
4. Нажать SOC → «Выбрать сущность HA» → поиск → выбрать датчик SOC; так же мощность,
   время работы, напряжение, температуру и несколько строк диагностики. Изменить подпись,
   иконку, точность, единицу; переставить строку; удалить строку с подтверждением;
   добавить свою строку. «Отмена» → «Не сохранять» — плитка без изменений.
   Повторить и «Сохранить».
5. Выйти из режима редактирования. Проверить компактный вид, стрелку и подпись
   направления (по фактическому знаку мощности), «Ожидание» при малой мощности.
   При необходимости — переключатель инверсии.
6. Тап по плитке — плавное раскрытие, размытый (Android 12+) или затемнённый фон.
   Вертикальная прокрутка списков не закрывает карточку; лёгкое касание закрывает;
   без касаний карточка сворачивается через ~30 с и возвращается на прежнее место.
7. Изменить размер и положение плитки в режиме редактирования; раскрытие использует
   новые координаты.
8. Потеря связи: только если владелец разрешит кратко отключить Wi‑Fi планшета —
   показания «—», нейтральная шкала, «Нет связи с Home Assistant»; после возврата
   сначала «Синхронизация…», затем актуальные значения.
9. Оставить панель на несколько часов с открытием/закрытием карточки; проверить
   отсутствие рывков и роста памяти (Android Studio Profiler), отсутствие ANR.
