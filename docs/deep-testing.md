# Глубокие проверки (0.9.13)

Задача владельца 07.11.2026 (вариант C): максимум бесплатных автоматических проверок, найденные дефекты исправить.
Всё работает в GitHub Actions публичного репозитория, без оплаты и без секретов. Реальный дом, Home Assistant,
камеры и планшеты не затрагиваются: только искусственные сущности, фальшивый HA и тестовые ролики.

Workflow: [.github/workflows/deep-tests.yml](../.github/workflows/deep-tests.yml). Ручной запуск — вкладка Actions →

(Summary) и в артефакте `emulator-report` (`deep-log.txt`); отчёт хаоса — артефакт `chaos-report`.

## Запуск локально

```bash
./gradlew testDebugUnitTest --tests '*PanelChaosTest*' -Pchaos.iterations=1500   # больше сочетаний
./gradlew testDebugUnitTest --tests '*PanelChaosTest*' -Pchaos.seed=7919         # повтор одного сочетания из отчёта
./gradlew connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.example.smarthomedashboard.deep.PanelEndToEndTest
```

Отчёт хаоса: `app/build/reports/chaos/panel-*.txt` — сбои сгруппированы по месту в коде, с сидами для повтора.
Тесты эмулятора с RTSP требуют аргумент `rtspHost` (адрес машины со стендом, для эмулятора — `10.0.2.2`);
без него пропускаются. Soak — только с аргументом `soakMinutes`.

**Только эмулятор.** Тесты `deep/` заменяют настройки и плитки приложения искусственными, поэтому на физическом
устройстве пропускаются (проверка `isEmulator()`, а `prepareApp` вдобавок прерывает тест до записи). Но сам Gradle
после `connectedDebugAndroidTest` удаляет приложение вместе с данными на любом устройстве — на настенном планшете
эту команду не запускать.

## Скриншот-эталоны

Визуальные тесты (`*VisualTest`, `*LookTest`, `PowerGraphTest`, `SettingsSectionsTest`, `ModernDesignSystemTest`)
сверяют рендер с эталоном в `app/src/test/golden/<группа>/<имя>.png`. Допуск — сглаживание: пиксель «другой» при
разнице канала больше 40, рендер «другой» при доле таких пикселей больше 0,4 %. Карта отличий —
`app/build/reports/golden-diff`. Намеренное изменение вида — новые эталоны:

```bash
./gradlew testDebugUnitTest -Pgolden.record
```

Сравнение только на Linux (эталоны сняты там, как и в CI): на Mac рендер шрифтов другой, проверка там пропускается.
Плитка часов и климата (`home-climate-visual`) и график мощности (`power-graph`, данные «от текущего момента») показывают настоящее время — без эталона.

## Образцы совместимости

`app/src/test/resources/compat/v*.json` записаны настоящим кодом прежних версий: в рабочей копии тега временно
запускался генератор, который создаёт плитки всех типов, существовавших в этой версии, её же шаблонами
(`newTileConfig`) и пишет `dashboard_prefs`, `tiles_prefs` и файл резервной копии (`ConfigBackup.build`).
Сущности и адреса искусственные. При изменении формата добавляйте образец новой версии; старые не удаляйте.
