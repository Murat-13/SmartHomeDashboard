# Электропитание Modern

Универсальная плитка `power_modern` для электрических линий через Home Assistant.
Две готовые конфигурации одной реализации: «Сеть · Вход» (профиль `grid_in`, иконка ЛЭП,
изумрудная норма) и «Инвертор · Выход» (`inverter_out`, иконка инвертора, бирюзовая норма).
Тот же компонент подходит для генератора, второго инвертора или отдельной линии: профиль
задаёт только шаблон, дальше у каждой плитки свои источники, правила и цвета.

## Компоненты

| Файл | Назначение |
| --- | --- |
| `PowerModernConfig` | Профили, строки (основные: напряжение, мощность, частота; дополнительные: ток, полная и реактивная мощность, cos φ, энергия, статус), правила напряжения, проверка пересечений и пропусков, JSON в `tile.config.power_modern`. |
| `PowerModernState` | `PowerStateTracker` (подтверждение 1,8 с, гистерезис 2 В, нейтральное состояние) и `PowerVisual` (цвет, статус, пульсация). Чистая логика без Views и времени. |
| `PowerModernCard` | Компактный и развёрнутый вид, векторные иконки (`ic_power_pylon`, `ic_power_inverter`, `ic_power_sine`), плавная смена цвета, мягкая пульсация, подгонка цифр. |
| `PowerModernDraft`, `PowerModernEditorActivity` | Черновик и редактор: показатели касанием, таблица правил, предпросмотр тестовым напряжением. |
| `ModernEditorKit` | Общие части редакторов АКБ Modern и Электропитание Modern: диалог строки, поиск сущностей, подсказки. |
| `BatteryModernExpansion` + `ModernOverlayCard` | Одна механика раскрытия для обеих Modern-плиток. |

Изменены: `DashboardPanelController` (создание, адресная отрисовка, раскрытие, проверки
подтверждения), `DashboardContentController`, `MainViewModel` (трекеры по id плитки),
`MainActivity` (маршрут редактора), `TileSettingsActivity` (два профиля в списке типов),
`UserHints`, `strings.xml`, манифест, `BatteryModernEditorActivity` (переход на общий набор).

## Стандартные правила

Границы с явным включением, без пересечений и пропусков от 0 В:

| Напряжение | Цвет | Статус | Пульсация |
| --- | --- | --- | --- |
| 0 | красный | «Нет сети» / «Нет напряжения на выходе» | да |
| > 0 … ≤ 150 | красный | Очень низкое напряжение | да |
| > 150 … < 170 | красный | Низкое напряжение | нет |
| 170 … < 190 | оранжевый | Пониженное напряжение | нет |
| 190 … < 200 | жёлтый | Нижняя граница | нет |
| 200 … < 240 | изумрудный / бирюзовый | Норма | нет |
| 240 … < 250 | жёлтый | Повышенное напряжение | нет |
| 250 … < 260 | оранжевый | Высокое напряжение | нет |
| 260 … < 280 | красный | Опасно высокое напряжение | нет |
| ≥ 280 | красный | Опасно высокое напряжение | да |

Это пользовательская таблица визуальных предупреждений, а не нормативная оценка безопасности.
Напряжение вне всех правил (например, отрицательное или в созданном пропуске) показывается
нейтрально: «Вне заданных диапазонов», никогда не «Норма».

## Состояния и переходы

- Цифры обновляются сразу; цвет следует только за собственным напряжением плитки.
- Любой новый диапазон — в том числе первое показание после запуска и после потери данных —
  окрашивает плитку только после 1,8 с удержания; до этого серо, «Определение состояния…»,
  без пульсации. Смена подтверждённого диапазона дополнительно требует выхода за его границу
  на гистерезис 2 В (кроме точечного правила «0 В»). Колебания у границы ожидание сбрасывают.
- Граница пульсации (правило с флагом и без него) пересекается без гистерезиса, но с тем же
  подтверждением 1,8 с: устойчивые 280 В после 279 В начинают пульсировать, устойчивые 151 В
  после 150 В — перестают. Колебания 279/280 В пульсацию не включают; колебания 150/151 В её
  не выключают (напряжение всё время возвращается в критическую зону) — без мерцания.
  Это же правило действует для пользовательских флагов пульсации.
- Подтверждённое состояние хранится во ViewModel: после пересоздания экрана новая View сразу
  показывает его (единственное исключение из ожидания). Предпросмотр редактора — мгновенный.
- Ожидание реализовано одной отложенной перерисовкой на плитку (`Handler`), без опроса.
- Цвет фона, рамки, свечения, иконки и статуса меняется за 500 мс; цифры всегда белые.
- Внешний ореол: тёмное тело рисуется с небольшим отступом (`HALO` = 8 px × масштаб) от границ
  карточки, в этом кольце — три полупрозрачных кольца цвета состояния, яркость убывает наружу и
  следует пульсации. Без размытия и без выделений памяти в `onDraw`. Контур (тень elevation) —
  по телу, обрезки по контуру нет; содержимое удерживает внутренний отступ. Сохранённые размеры,
  координаты, область касания, resize/перемещение и соседние плитки не меняются.
- Пульсация (~1 Гц, яркость рамки и свечения 45–100 %) — только у правил с флагом и только у
  действительно видимой карточки: прикреплена, все родители видимы (`isShown`,
  `onVisibilityChanged`), окно показано (`onWindowVisibilityChanged`) и исходная плитка не скрыта
  раскрытием (`ModernHideAware`). Скрытая карточка не держит аниматоры: переход цвета сразу
  завершается целевым цветом, пульсация останавливается и возобновляется при показе.
  Подтверждённое состояние, цифры, события HA и отложенные проверки подтверждения продолжают работать.
- Нет связи / идёт синхронизация / напряжение не выбрано, не найдено, unknown, unavailable —
  сразу серый цвет без пульсации, понятный статус, недостоверные значения «—». Хранилище HA
  не очищается. После переподключения цвет появляется только по данным новой сессии и после
  подтверждения. Без мощности — «— Вт» при окраске по напряжению; без напряжения — серо даже
  при доступной мощности.

## Отображение

- Компакт: напряжение и мощность одинакового размера, целые (математическое округление
  только при показе, знак сохраняется, без «−0», без кВ/кВт), частота — 1 знак. Размеры цифр —
  в px от размеров плитки и подгоняются по ширине и высоте после layout, поэтому системный
  масштаб шрифта не обрезает цифры. При масштабе ниже 0,72 скрывается блок частоты.
- Развёрнутый вид по эскизу: слева линия, статус, крупные напряжение и мощность, частота;
  справа прокручиваемые строки с выбранной иконкой (набор АКБ Modern, цвет состояния); смена иконки
  и новые показания обновляют строку на месте, без пересоздания. Напряжение — не больше 1 знака и не больше, чем в данных;
  мощность — точность источника (до 2 знаков) или выбранная; частота — точность источника, но не
  больше 2 знаков и без искусственных нулей (50 → «50», 50.1 → «50,1», 50.12345 → «50,12»);
  явный выбор точности пользователем сохраняется. Полная и реактивная
  мощность не рассчитываются: без датчика — «—». Строка «Статус» без источника показывает
  вычисленный статус.
- Раскрытие, размытие, закрытие тапом, прокрутка, 30 с автосворачивания, пауза при потере
  фокуса — общая механика АКБ Modern; события HA таймер не продлевают.

## Редактор

В режиме редактирования панели тап по плитке открывает редактор. Тап по напряжению,
мощности, частоте или строке справа — выбор сущности с поиском (только уже известные панели
сущности, без нового подключения), подпись, иконка, точность, единица, видимость, порядок,
удаление с подтверждением, произвольные новые строки. Таблица правил: границы с флагами
включения, цвет (палитра или #RRGGBB), статус, пульсация, порядок, удаление, восстановление
шаблона. Пересечения и пустые диапазоны блокируют сохранение; пропуски требуют подтверждения.
Предпросмотр тестовым напряжением (кнопки 0, 145, 180, 195, 228, 245, 255, 285) показывает
цвет, статус и пульсацию без HA. Запись — только «Сохранить»; отмена не меняет плитку.

## Как создать плитки

Режим редактирования → «+» → тип «Электропитание Modern — Сеть · Вход» (или «— Инвертор · Выход»)
→ название подставится, можно изменить → «Сохранить». Плитка ставится на свободное место.
Затем тап по ней в режиме редактирования → выбрать датчики напряжения, мощности, частоты и
дополнительных строк → «Сохранить». Повторить для второго профиля.

## Ограничения

- Планшет не проверялся; работа 24/7, CPU/память, плавность и вид свечения на реальном экране
  не измерялись. Размытие при раскрытии — та же реализация, что у АКБ Modern (API 31+).
- Видимое тёмное тело меньше сохранённого размера плитки на ширину кольца ореола (≈8 px × масштаб
  с каждой стороны); цифры подгоняются под тело. Вид рядом с другими плитками — проверить на планшете.
- Параметры 1,8 с / 500 мс / 2 В хранятся в config, но в редакторе не выводятся.
- Профиль меняется только при создании; смена пункта профиля у существующей плитки не
  перезаписывает её настройки.

## Проверка на планшете (только с разрешения владельца)

Команды дому не отправляются; данные приложения не очищать.

1. Установить поверх текущей версии. Убедиться, что АКБ Modern, Classic и кнопки не изменились.
2. Создать обе плитки (см. выше), назначить датчики. Проверить крупные белые цифры, частоту,
   иконки и цвет по фактическому напряжению; изменить размер и положение.
3. Раскрыть плитку: размытие, правые строки, прокрутка, закрытие тапом, автосворачивание ~30 с.
4. В редакторе: предпросмотр 0…285 В, изменение цвета нормы и подписи, «Отмена» и «Сохранить».
5. Только по отдельному решению владельца: кратковременная потеря связи (серый цвет, «Нет связи
   с Home Assistant», затем через ~1,8 с после восстановления — цвет).
6. Длительная работа: отсутствие рывков и роста памяти (Android Studio Profiler).
