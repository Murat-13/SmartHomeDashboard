# Единый редактор сенсорной плитки

Редактор объединяет показания, подробный вид, размер текста, цветовые правила
и предпросмотр. Применяется к типу «Сенсор (отображение данных)»; кнопки, группы,
аккумулятор, часы и погода сохраняют прежние формы и возможности.

## Использование

1. Добавьте плитку, задайте название и нажмите «Добавить показания».
2. Выбранные датчики сразу появляются в списке и предпросмотре. Для новых строк
   используются доступные имена и единицы HA; при отсутствии данных показывается
   соответствующая подсказка. Сохранённые подписи не переименовываются автоматически.
3. Нажмите строку для изменения подписи, точности или замены источника. Замена
   сохраняет подпись и точность. Удержание позволяет перетаскивать строки; стрелки также меняют порядок, «×» убирает строку.
4. По умолчанию раскрытая плитка повторяет основной список. Можно отключить
   «При раскрытии — тот же список» и настроить отдельные подробные показания.
   Уже существующий самостоятельный подробный набор открывается как самостоятельный.
5. Раздел «Цвет по условиям» доступен также по верхней кнопке с количеством правил.
6. «Сохранить» применяет все изменения одной записью плитки. «Отмена» и выход назад
   позволяют сохранить, отбросить черновик или продолжить редактирование.
   Никаких промежуточных сохранений при выборе источников нет.

Новая полностью пустая карточка не сохраняется по ошибке: редактор просит добавить
показание. У существующих плиток намеренно пустое отображение остаётся допустимым.
Удаление существующей плитки требует подтверждения.

## Цветовые правила

- Источник любого правила независим от отображаемых строк. Удаление или замена
  строки не удаляет и не переназначает её цветовые правила.
- Сохранены числовые и текстовые условия, отрицательные/дробные границы,
  прозрачность цветов, все 32 прежних цвета палитры и порядок правил.
- Добавлен ввод собственного цвета #RRGGBB / #AARRGGBB с проверкой формата.
- Стрелки меняют приоритет: применяется последнее совпавшее правило. Предпросмотр
  сообщает номер совпавшего правила и использует тот же matcher и renderer, что панель.
- «Проверить цвет на пробном значении» подставляет локальный текст только в
  предпросмотр выбранного источника. Реальные состояния HA, настройки и устройства
  не изменяются. unknown/unavailable не становятся допустимым числовым показанием.

## Совместимость и устройство

`SensorTileDraft` содержит единственный черновик строк, подробного набора, шрифта
и правил без Context, prefs или сети. Неизменённые config/colorRules сохраняются
побайтово; дополнительные неизвестные поля сохраняются при редактировании,
включая поля отдельных строк и правил. Старые формы конфигурации читаются,
новых обязательных полей и новой версии формата нет.

Простой старый выбор entity_id/entity_ids теперь используется сенсорной плиткой,
если не задан отдельный свёрнутый набор и нет старого непустого collapsedSensorIds.
Явно настроенные наборы имеют прежний приоритет, явный пустой набор не заменяется
автоматическим выбором. Подробный вид использует прежние правила fallback.

Совместное отображение сохраняется существующими полями expanded_sensor_configs
и entity_ids, без отдельного нового флага формата. После явного выбора совместного
режима и сохранения отдельный подробный набор заменяется основным. До сохранения
переключение обратно возвращает его из черновика.

`SensorTileEditor` строит UI черновика и применяет существующие SensorContentRenderer,
SensorValueFormatter, SensorBackgroundRenderer и ColorRuleMatcher. Обработчики
цвета и сама отрисовка рабочей панели не переписаны. При повреждённых настройках
запись блокируется с пояснением. Устаревший редактор не может перезаписать плитку,
изменённую или удалённую другим экраном.

Предпросмотр читает существующий StateFlow MainViewModel через слабую ссылку
TileEditorPreviewSource. Не открывает дополнительного HA-соединения и не отправляет
команд. Выбор источников использует Activity Result API с восстановлением ожидающего запроса.
Открытые диалоги закрываются при уничтожении редактора. Наблюдение начинается
в onStart и отменяется в onStop; обновляются только
зависимые показания/атрибуты. Неизменная структура предпросмотра переиспользует строки.
Не добавлены периодические таймеры, зависимости или SDK-требования.

Черновик, ожидаемый выбор источника, режим предпросмотра и пробное значение
восстанавливаются после пересоздания Activity отдельно от пользовательских prefs.
Неподтверждённый ввод внутри открытого диалога подписи/цвета остаётся локальным
этому диалогу; подтверждённые изменения включаются в общий черновик.

## Приёмка на планшете

Новый редактор пока не установлен на физический планшет. На нём остаётся версия
25567bc, проверенная ранее. Перед обновлением: подтвердить сохранение существующей
плитки без изменений, создание/удаление временной сенсорной плитки, отдельный
подробный вид, скрытый источник правила, приоритет и прозрачность цветов,
работу клавиатуры/прокрутки, отмену и пересоздание экрана. Установка требует
отдельного разрешения владельца; реальные команды дому для этой проверки не нужны.

Изменения сохранены локально в main. В GitHub и релиз они не публиковались.
