# Стенд «замки и ворота»

Поддельные реле Shelly Gen2 на Mac — чтобы проверить калитки и ворота без настоящего железа и без Home Assistant
(docs/gate-tz.md, этап 4). Без сторонних программ, только Python 3.

| Порт | Устройство | Что умеет |
|---|---|---|
| 8091 | реле калитки (как Shelly Plus 1) | `Switch.Set` с `toggle_after` — импульс, реле выключается само; вход 0 — датчик двери: через 0,8 с после импульса дверь «открывается» на 6 с |
| 8092 | привод ворот (как Shelly Plus 2PM в режиме ворот) | `Cover.Open / Close / Stop / GetStatus`, ход 12 с с положением в процентах; вход 0 — «ворота не закрыты» |

Запуск (адрес Mac в домашней сети — чтобы планшет его видел; пароль — по желанию, как у Shelly: пользователь `admin`):

```bash
python3 -I tools/lock-stand/lockstand.py --bind <адрес Mac> --password <пароль>
```

- В журнал стенда пишутся только действия («реле калитки: включено на 3 с», «привод ворот: открываются») и неверный
  пароль — без адресов.
- `kill -USR1 <pid>` — стенд «пропадает из сети» на 20 с: панель должна показать «устройство не отвечает».
- В приложении: Настройки → «Устройство» → «Калитки и ворота» → проход → «Связь» → «Только напрямую» → Shelly, адрес
  `<адрес Mac>:8091` (или `:8092`), вход 0, пароль.
